# Additional apps by Drew Wichman

These 26 project snapshots were added on October 25, 2026 for import into Google AI Studio or other development tools. They are intentionally absent from the Music Arcade homepage and app directory.

Each folder preserves the project layout: source code, bundled media, dependencies and lockfiles when present, build scripts, tests, and documentation. Static projects include their `dist` folder. Framework projects retain their full source and need their dependencies installed and a compatible build/runtime. This upload does not migrate databases, browser-saved projects, runtime secrets, or ChatGPT plugin connections.

## Importing a project

Use the individual folder above as the project root. Each project's existing README and package.json describe its own structure. Framework apps may use Cloudflare, Vinext, ChatGPT sign-in, or server/plugin features that must be adapted in another host. Being stored here does not deploy those server features on GitHub Pages.

The original hosted apps and their access settings remain unchanged. This repository is public by the owner's request for import access. No links were added to `index.html`, `apps.js`, or `directory.html`.

Generated dependency folders and caches, `.openai` hosting identity, and runtime/private configuration are excluded. No app source or bundled runtime asset was intentionally omitted. Original source commit IDs and file hashes are retained in the migration records.
