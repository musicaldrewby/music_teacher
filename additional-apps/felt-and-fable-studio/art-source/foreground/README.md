# Felt foreground overlays

Four full-stage foreground overlays generated individually with the built-in image tool: leafy branches, parted theater curtains, stone arch, and harbor railing corners.

All images use a wide 1672 × 941 canvas and genuine transparent alpha for their open areas. Place at full stage size in the foreground layer. The content deliberately meets the image edges so no narrow frame seam appears.

Original PNGs are retained here. Runtime WebP images are in `art-source/cinema/foreground/`; their alpha channels are byte-for-byte preserved from the source PNGs. Prompts, dimensions, and runtime paths are recorded in `manifest.json`.

Verified the central region contains no visible matte (alpha maximum 1 of 255), and inspected framing and material style in all four generated images. No automatic background erasing was used.
