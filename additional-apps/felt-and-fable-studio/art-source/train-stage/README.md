# Train Journey and Backstage & Showtime artwork

Sixteen assets created with the built-in image generation tool for Felt & Fable Studio.

- Eight wide felt story backgrounds, approximately 16:9.
- Eight separate felt props with generated transparent alpha.
- Original PNG images are kept here.
- Optimized WebP runtime assets are in `art-source/cinema/train-stage/`.
- `manifest.json` preserves each asset's prompt, dimensions, theme, and runtime path.
- WebP conversion changes encoding only, preserving the original image dimensions and alpha channel. No background erasing or cutout processing was used.

The visual reference was the existing `bg61.webp` school cafeteria: clean tactile felt, tiny fibers, warm colors, softly dimensional environmental sets, and flat felt-cutout props.

Train palette: deep teal, cream, walnut, and ochre. Theatre palette: burgundy, cream, walnut, teal, and ochre. All backgrounds are empty of characters and writing for flexible scene composition.
