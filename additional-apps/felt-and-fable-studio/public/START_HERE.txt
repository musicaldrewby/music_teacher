Open the site to start making stories. Artwork loads as you use it.

Sound adds music and scene narration. Export makes a video or a still image.
Use Download story to keep an editable project, including imported images and audio.
Use File > Open story to restore a project from the desktop folder app or this site.
Edits create recovery copies in this browser on this device, including images and audio.
File > Recover recent story offers up to eight recent editing sessions.
Recovery is not cloud saving. Clearing browser site data removes recovery copies.
Download a story file for a lasting backup or to continue on a different computer.
Chrome or Edge is recommended for the existing MP4 export feature.
Quick tour walks through a first story. File > Guide & shortcuts explains more tools.
Use the star on a piece or backdrop for Favorites. Recently used helps find it again.
Workspace zoom changes your editing view; Camera zoom changes the recorded shot.

Click a piece for nearby Duplicate, Delete and More actions.
Select several pieces for Group, or one group for Ungroup.
Locked pieces are protected. Undo in the top toolbar reverses a deletion.
