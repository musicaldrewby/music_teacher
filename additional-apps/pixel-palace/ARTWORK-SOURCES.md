# Character artwork and gameplay references

The second edition uses official promotional character artwork. Local WebP versions preserve transparency and are resized only for web performance; the reel layout crops them with CSS. These characters and images remain the property of their respective owners. Pixel Palace is an independent, private fan prototype.
