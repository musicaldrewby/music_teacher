# Boomwhacker Play-Along — Teacher Edition

Public classroom edition of Drew Wichman's app. Static entry point: `dist/index.html`.

Composition, project files, samples, artwork, lyrics, MIDI, Record Along, and live performance are retained. Export video opens a Creator Edition upgrade dialog linking to Mr. Drew's Music Lab on Teachers Pay Teachers. This deployment does not ship the MP4 muxer or video/audio encoder pipeline. The direct Creator product URL can replace the store link when available.

The Teacher Edition manual is hosted at `dist/docs/Boomwhacker_Teacher_Edition_Manual.pdf` and linked from Help. Legacy export preferences remain in project validation for save-file compatibility.

Creator Edition was preserved separately as an owner-private Site before this conversion. Do not copy its export-enabled app or Creator manual into this public deployment.
