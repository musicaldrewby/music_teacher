# Board material assets

Generated with the built-in image generation tool, then encoded to WebP for delivery. Final assets: dist/assets/materials/{walnut,marble,ice,copper}.webp. Titanium reuses brushed-steel.png with a darker static finish; obsidian and ceramic use CSS reflections; carbon-weave.svg is a repeating vector weave.
