USE YOUR EXISTING GITHUB HOMEPAGE ADDRESS

1. Unzip this package on your computer.
2. Open the same GitHub repository and publishing folder that currently contains your homepage's index.html.
3. Upload the extracted index.html, app.js, apps.js, style.css, directory.html, and assets folder into that same folder. Include .nojekyll if your file browser shows it. Preserve the assets folder structure.
4. Replace your existing homepage index.html and matching support files. Keep unrelated repository files, any existing CNAME file, and your current GitHub Pages settings. The README is for you and is optional to upload.
5. Commit the uploaded files. When your existing GitHub Pages publication finishes, open your usual homepage address. Refresh the page if your browser is showing the previous design.

Upload the EXTRACTED CONTENTS, not this ZIP and not an extra enclosing folder. index.html must stay where your existing homepage index.html is published to keep the same URL.

WHAT IS INCLUDED

All 15 approved apps below, with exact GPT Site destinations. The four unselected apps and their coming-soon entries are removed from the directory. Your original record-shop design, solid wooden backing, category tabs, featured albums, search, favorites, animations, mobile browsing, and Buy Me a Coffee link are included.
