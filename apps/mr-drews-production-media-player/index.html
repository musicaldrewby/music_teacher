Rehearsal points

A calmer show day.

  1. Prepare your program. Add tracks, stage reminders, and sound effects. Edit Show reveals reorder and cue-edit buttons. Each cue can have a private reminder.
  2. Save a portable copy. Save Show downloads one JSON file containing your audio, slides, levels, and running order. Open Show also accepts projects from the original player. Device recovery is a convenience; keep a downloaded show file.
  3. Get ready. Ready to Run enables sound without playing a cue. Use Test Sound to check your actual speakers. Open Projector and move its window to the audience display.
  4. Run the show. Selecting a row only makes it next. GO starts that cue and selects the next one. Cues wait for you by default. A music cue replaces the current music; sound effects and stage reminders can run alongside it.
  5. Stay in control. Clicking a playing effect never restarts it. Fade and Stop are separate. Stop All silences music, effects, and the test sound, cancels automatic continuation, and keeps your next cue selected.
  6. Slides. Record Timings starts the track and shows the first slide. Press Space for each new slide, then Finish & keep. Previous / Next switches to manual slides until you choose Resume Timed Slides. Blank Screen hides the audience text while music continues.
  7. Rehearse. Add named time points in a track’s editor. Jump uses the current music track’s points, or the selected track when nothing is playing. A jump while paused stays paused.
Keyboard shortcuts
Space — GO · P — Pause / Resume
F — Fade music · Escape — Stop All
← / → — Previous / Next slide · B — Blank Screen
Shortcuts are off while typing or using a dialog. During timing recording, Space advances slides.

The downloaded HTML has no online dependencies. Your audio stays in your show file and this browser’s recovery storage. Keep the player visible during a performance and test the show on the device and sound system you will use.
